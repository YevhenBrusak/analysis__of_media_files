# Лабораторна робота 3 — розпізнавання, аналіз та пошук у тексті з аудіофайлу

Файл **lab3_app.py** — це консольний застосунок, який виконує повний цикл обробки аудіо:

1. Розпізнає текст у WAV-файлі через **AWS Transcribe**.  
2. Визначає мову отриманого тексту (через **langdetect**).  
3. Аналізує настрій тексту (**NLTK Sentiment Analyzer**).  
4. Виконує пошук введеної фрази у транскрипті.  
5. Визначає іменовані сутності за допомогою **spaCy** (модель `en_core_web_sm`).  

Вихідний файл для тестування: **lab3.wav** (згенеровано через gTTS).

---

## Вимоги

- Python 3.9+
- Обліковий запис AWS з доступом до Transcribe та S3
- WAV-файл має бути завантажений у S3 bucket
- Пакети Python:
  -boto3
  -langdetect
  -nltk
  -spacy
  -python-dotenv
  -requests

  ## Інтерфейс запуску
  `python lab3_app.py --audio-source lab3.wav --phrase "your phrase"`
  Параметри:
- `--audio-source` — назва WAV-файлу в S3
- `--phrase` — фраза, яку потрібно знайти у розпізнаному тексті

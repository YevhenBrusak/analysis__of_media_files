# Лабораторна робота 5 — обробка JPEG зображення: EXIF, валідація, виявлення облич

Цей Python-скрипт виконує:

1. **Перевірку валідності JPEG-файлу**  
   - Перевіряє існування файлу  
   - Перевіряє, що зображення дійсно формату JPEG  
   - Перевіряє цілісність (через `Pillow.verify()`)

2. **Отримання EXIF-метаданих**  
   - Зчитує EXIF через `Pillow`  
   - Зберігає метадані у файл формату JSON:  
     **<ім'я_файлу>_metadata.json**

3. **Виявлення фронтальних облич**  
   - Використовується `OpenCV` + каскад Хаара  
   - На оригінальному зображенні малюються **червоні рамки**  
   - Зберігається результат як:  
     **<ім'я_файлу>_faces.jpg**

---

## 🛠 Використані бібліотеки

- **Pillow** — робота з JPEG + EXIF  
- **OpenCV (opencv-python)** — детекція облич  
- **haarcascade_frontalface_default.xml** (вбудований у OpenCV)

Встановлення залежностей:
`pip install Pillow opencv-python`
## ▶ Запуск
`python lab_jpeg_faces.py new_york.jpeg`
